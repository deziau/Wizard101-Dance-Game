# Wizard101 Dance Game Helper

Records arrow sequences during the Wizard101 pet dance minigame show phase and keeps them visible so you can input them perfectly every time.

## How the Dance Game Works

1. **Show phase**: The game displays arrows one at a time (up/down/left/right) — you watch and memorize
2. **Input phase**: You enter the same arrows in the same order from memory
3. Getting all arrows correct = 5/5 score = maximum pet XP

## What This Tool Does

1. Watches the area where arrows appear during the show phase
2. Records each arrow direction as it changes using OpenCV template matching
3. Keeps the full sequence visible in an overlay so you never forget
4. Optionally auto-inputs the arrows for you during the input phase

## Requirements

- Python 3.10+
- Windows (Wizard101 is a Windows game)
- Wizard101 running in **windowed mode**

## Setup

```bash
pip install -r requirements.txt
```

## Calibration (First Time)

### Step 1: Capture screenshots during gameplay

```bash
python -m src.main --capture
```

Press **F8** during the show phase (when an arrow is visible) to save a screenshot. Press F10 to stop.

### Step 2: Calibrate from a saved screenshot

```bash
python -m src.main --calibrate
```

The wizard walks you through:
1. **Pick a screenshot** from your saved captures
2. **Draw a box** around where the arrow appears during the show phase
3. **Crop ONE arrow** — draw a tight box around any single arrow
4. **Select its direction** — the other 3 are auto-generated by rotation

## Usage

### Display Mode (shows the sequence, you type it)
```bash
python -m src.main --mode display
```

The overlay shows:
- **Yellow** = currently recording arrows during show phase
- **Green** = sequence ready — enter them now!

### Auto-Play Mode (inputs the arrows for you)
```bash
python -m src.main --mode auto
```

Records the sequence during the show phase, then automatically presses the arrow keys during the input phase.

### Debug Mode
```bash
python -m src.main --mode display --debug
```

Shows a window with detection rectangles and the current phase.

### All Options
```
--capture            Save screenshots during gameplay (F8 to save, F10 to stop)
--calibrate          Run calibration wizard
--mode {display,auto} Output mode (default: display)
--config PATH        Custom config file path
--debug              Show debug detection window
--threshold FLOAT    Override detection confidence (0.0-1.0)
```

## Hotkeys

| Key | Action |
|-----|--------|
| F8  | Save screenshot (capture mode only) |
| F9  | Toggle auto-input on/off (auto mode only) |
| F10 | Quit the program |

## Troubleshooting

- **Not detecting arrows**: Lower the threshold with `--threshold 0.5`. Use `--debug` to see what's being captured.
- **False detections**: Raise the threshold with `--threshold 0.85`.
- **Recording wrong arrows**: The capture region may be too large — re-run `--calibrate` and draw a tighter box around just the arrow display area.
- **Game window moved**: Re-run `--calibrate` since the capture region uses absolute screen coordinates.
